# 1.01.1 Итог: Визитка

**Тема:** 1.01 Каркас страницы и первые теги · **Балл: 5 / 10** · 2026-10-29

## Суть теории
- HTML — язык разметки: он говорит браузеру, *что* есть на странице.
- Элемент = открывающий тег + содержимое + закрывающий тег (`</...>`). Атрибуты пишутся в открывающем теге: `имя="значение"`.
- Пустые элементы (`<img>`, `<meta>`, `<br>`) не закрываются: у них нет содержимого.
- Вложенность как у матрёшки: что открыл последним, закрываешь первым.
- Каркас: `<!DOCTYPE html>` (современный HTML5) → `<html lang="ru">` (корень, весь «человек») → `<head>` (паспорт, не виден: `meta charset`, `title`) → `<body>` (всё видимое).

## Задание
Страница-визитка: полный каркас, `<h1>` с именем, `<h2>` «Обо мне» и два абзаца (кто ты, зачем учишь веб) с одним `<strong>` и одним `<em>`, картинка с осмысленным `alt`, ссылка на GitHub в новой вкладке, комментарии над каждым куском, аккуратные отступы.

## Исправленный код
```html
<!DOCTYPE html>
<html lang="ru">
  <!-- Паспорт страницы: служебная информация, на странице не видна -->
  <head>
    <meta charset="utf-8">
    <title>Визитка — Александр</title>
  </head>

  <!-- Тело: всё, что видит пользователь -->
  <body>
    <!-- Имя -->
    <h1>Александр</h1>

    <!-- Блок «Обо мне» -->
    <h2>Обо мне</h2>
    <p>Меня зовут Александр, я заново учу фронтенд, чтобы <strong>самому</strong> делать сайты, а не просить об этом ИИ.</p>
    <p>Летом я уже проходил HTML и CSS, но всё забыл. Теперь хочу <em>по-настоящему</em> разобраться и выложить свой сайт по реальной ссылке.</p>

    <!-- Картинка -->
    <img src="https://images.prom.ua/6552777201_w1280_h640_6552777201.jpg" alt="Губка Боб улыбается и машет рукой">

    <!-- Ссылка на GitHub, открывается в новой вкладке -->
    <p>Мой код:</p>
    <a href="https://github.com/astireh" target="_blank">Мой GitHub</a>
  </body>
</html>
```

## Ошибки
**Подготовка**
- Почти все пропуски пустые.
- Корневым элементом назван `<Head>` вместо `<html>`, а «паспортом» — `<title>` вместо `<head>`. Роли частей каркаса перепутаны.
- `lang="ру, Россия"` вместо кода языка `ru`.
- Атрибут описания картинки назван `score` вместо `alt`.
- Доктайп не записан: `<!DOCTYPE html>`.

**Код**
- Комментарии не над каждым куском, а только два, в конце строк, и неинформативные.
- `head` и `body` без отступа внутри `html`.
- Пробелы внутри `<strong>`/`<em>`.

Текст страницы (шутки, упрощения, ник во вкладке) на балл не влияет.

**Что получилось:** каркас в правильном порядке, все теги закрыты верно, перекрещивания нет, `target="_blank"` на месте.
